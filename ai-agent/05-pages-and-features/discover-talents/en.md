# Discover Talents

## What It Is

A page for discovering volunteers and talents on the platform. It is one of the important pages in the project's idea.

## The Logic

People are discovered through their skills and experience, not through popularity. There are no likes, followers, or popularity rankings.

## Filters

The page supports:

- A keyword search over username, first and last name, and biography.
- One or more skills.
- A category.
- One or more wilayas.
- A minimum number of experiences.
- Availability.
- Portfolio.

## Sorting

Results can be sorted by newest, oldest, or most experiences.

## Who Uses It

- Organizations looking for volunteers with specific skills.
- Visitors who want to see public talents and public volunteer profiles.

## Privacy

Only public data is shown. Private user data is never shown. A profile that is not public does not appear.

## Common Questions

**What is Discover Talents?**
A page for finding volunteers by their skills and verified experience.

**Is it ranked by popularity?**
No. There is no popularity ranking.

**Can I see private information about volunteers?**
No. Only the public profile content is shown.

**How can an organization find a volunteer with design skills?**
Use Discover Talents and filter by the design skill, then review public profiles and Verified Experiences.

**Can I search by name?**
Yes. The keyword search covers username, first and last name, and biography.

**Can I filter by wilaya?**
Yes. You can select one or more wilayas.
