# Portfolio

## What It Is

The portfolio is a showcase of a volunteer's work items. It is independent of Verified Experiences: a portfolio item does not need verification, and a Verified Experience is not a portfolio item.

## What a Portfolio Item Contains

- A title.
- An optional description.
- Optional media attachments.
- A visibility setting: public or private.
- An order position.
- An optional type label of up to 40 characters.
- Optional tags: up to 10 tags, each up to 30 characters.

## Managing the Portfolio

A volunteer can add, edit, delete, and reorder portfolio items from the portfolio page. The order is saved as a complete list.

## Public Portfolio

Only public portfolio items are shown on the public profile. Private items and private media are never shown publicly. A dedicated public portfolio page is available for an enabled public profile.

## Portfolio and Verified Experiences

Verified Experiences prove that an organization confirmed the work. Portfolio items present work the volunteer chooses to show. They serve different purposes and can be used together.

## Common Questions

**What is the portfolio?**
A place where a volunteer shows work items.

**Is a portfolio item verified?**
No. Portfolio items do not need verification.

**Can I choose which items are public?**
Yes. Each item has a public or private visibility setting.

**Can I reorder items?**
Yes. The full order is saved.

**Are private items shown on my public profile?**
No. Only public items are shown.

**Can I add tags?**
Yes. Up to 10 tags, each up to 30 characters.

**Does a portfolio item replace a Verified Experience?**
No. They are different: a portfolio item is self-presented work, while a Verified Experience is confirmed by an organization.
