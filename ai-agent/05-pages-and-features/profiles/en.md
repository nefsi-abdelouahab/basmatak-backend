# Profiles: My Profile and Public Profile

## Public Profile

The profile that others can explore. Its key content is the volunteer's Verified Experiences, so it works as a way to show the work the person actually did.

## My Profile

The user's own profile, where they manage their information and content.

## Volunteer Profile

A volunteer can:

- Present personal and professional information.
- List skills.
- Build a record that reflects actual contributions.
- Add portfolio items.
- Control public visibility settings.

## Volunteer Public Defaults

The public profile is on by default. These settings are on by default:

- Biography.
- Skills.
- Experiences.
- Portfolio.
- Statistics.

These settings are off by default:

- Avatar.
- Location.
- Availability.

The full name is always shown on the public profile. Email and phone are never shown.

A volunteer can change these settings from the profile settings. When a setting is off, that block is not shown publicly.

## Organization Profile

An organization has a public profile that describes it. It can show:

- The organization's Arabic and English names.
- The registry code.
- A description.
- A logo and cover.
- Location and address.
- Website.
- Founded year.
- A verified badge.
- Public contact details.
- Focus fields and operating scope.
- Statistics.
- Public opportunities.

Only verified, active organizations are public.

## Skills vs Proof

Skills listed on a profile are claims. Proof comes from Verified Experiences.

## Common Questions

**What is the difference between My Profile and Public Profile?**
My Profile is your private editing view. The Public Profile is what others can see.

**What is shown on my public profile by default?**
Biography, skills, experiences, portfolio, and statistics. Avatar, location, and availability are hidden by default.

**Is my full name always shown?**
Yes. The full name is always shown on the public profile.

**Can people see my email or phone?**
No. Email and phone are never shown on the public profile.

**Can I hide my experiences?**
Yes, from the public profile settings. When the setting is off, the experiences block is not shown.

**Why can't I find an organization's public profile?**
Only verified, active organizations are public.

**Does listing a skill prove I have it?**
No. A skill is a claim; a Verified Experience is proof.
