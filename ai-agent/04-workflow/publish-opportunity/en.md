# Publishing an Opportunity

Only organizations publish opportunities. Volunteers and visitors cannot.

## Before Publishing

The organization account must be verified and active. An organization that is not verified cannot publish.

## Building the Opportunity

An opportunity is built around a need the organization wants volunteers to fulfill. It can include:

- A title and description.
- A category and location.
- One or more positions. Each position has a title, a description, a required number of volunteers, required skills, deliverables, and an optional start time.
- An optional mode: on-site, remote, or hybrid.
- Optional prerequisites and a cover image.
- An optional start date, end date, duration, and application deadline.

The opportunity is created as a draft first. The organization can edit the full profile while it is a draft.

## Publishing

Publishing moves the opportunity from draft to published. A published opportunity appears in the public feed and accepts applications while positions have open seats.

## Publishing Gate

An organization may be temporarily blocked from publishing new opportunities when too many of its opportunities have contributions waiting for review. The default threshold is 3 and it is configurable. Publishing unlocks after the pending contributions are reviewed.

## After Publishing

Some fields become locked. The organization can still edit the description, move the application deadline forward, and change the cover while no participant has been accepted.

## Common Questions

**Who can publish an opportunity?**
Only a verified, active Organization account.

**Why can't my organization publish?**
The account may not be verified or active, or too many contributions may be waiting for review.

**Can I edit an opportunity after publishing?**
Only a limited set of fields, and only while no participant has been accepted.

**Can I delete a published opportunity?**
No. Only a draft can be deleted.

**How many positions can an opportunity have?**
I do not have confirmed information about a maximum number of positions. Each position has its own required number of volunteers.
