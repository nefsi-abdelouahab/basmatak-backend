# Publishing an Opportunity

Only organizations publish opportunities. Volunteers and visitors cannot.

## Idea
An opportunity is built around a need the organization wants volunteers to fulfill.

## Information an Opportunity Is Expected to Include
- Opportunity title.
- Description of the activity.
- Required skills.
- Nature of the task.
- Number of volunteers needed.
- Information about the organizing party.
- Date and place, when needed.

Note: this list reflects the expected information based on how the system works. The exact form fields are not confirmed in this knowledge base. If asked for exact fields, say that the exact fields may differ and suggest checking the creation page.

## Multiple Volunteers
One opportunity can accommodate several volunteers.

## Steps for an Organization
1. Sign in with an Organization account.
2. Open the opportunity creation page.
3. Describe the activity, the tasks, and the required skills.
4. Set the number of volunteers needed.
5. Publish.

## Visibility
Published opportunities can be explored by volunteers. Visitors can also view opportunity details, but cannot apply.

## Common Questions
**Who can publish an opportunity?**
Only Organization accounts.

**Can I publish an opportunity as a volunteer?**
No. If you represent an organization, you need an Organization account. An account type cannot be changed after registration, so a new account is needed.

**Can one opportunity have several volunteers?**
Yes.

**What should I write in an opportunity?**
A clear title, a description of the activity and tasks, the required skills, and the number of volunteers needed.
