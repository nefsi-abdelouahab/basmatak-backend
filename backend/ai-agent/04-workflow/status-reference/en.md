# Status Reference for Applications, Participation, and Submissions

## Application Statuses

| Status | Meaning |
|---|---|
| Pending | Sent and waiting for the organization |
| Under review | The organization is reviewing it |
| Accepted | Accepted; a participation is created and one seat is filled |
| Rejected | Rejected with a reason |
| Withdrawn | Withdrawn by the volunteer |

A live application is pending, under review, or accepted. A volunteer can have one live application per position. A rejection requires a reason of up to 2000 characters.

## Participation Statuses

| Status | Meaning |
|---|---|
| Accepted | Accepted; the task has not started |
| Active | The opportunity started and the work is under way |
| Completed | The contribution was verified |
| Withdrawn | The volunteer withdrew before completion; the seat is freed |
| Removed | The organization removed the participant with a reason; the seat is not freed |

## Submission Statuses

| Status | Meaning |
|---|---|
| Draft | Being prepared and not yet sent |
| Submitted | Sent and waiting for the organization |
| Under review | The organization is reviewing it |
| Approved | Verified by the organization |
| Rejected | Rejected with a reason; the volunteer can edit and resubmit |

A participation has one submission. A rejected submission returns to draft when edited. The Submit Contribution page shows the rejection reason under the rejected contribution, and the reason is written by the organization. The reason stays visible while the submission is rejected or in draft after editing, and it disappears when the submission is submitted again.

## Verification Outcomes

A verification is terminal: verified or rejected. It is created only when the organization decides. There is no pending verification state visible to users.

## Common Questions

**What is the difference between an application and a participation?**
An application is a request to join. A participation exists only after the organization accepts the application.

**Can a rejected application become pending again?**
No. A rejected application is final, but the volunteer can send a new application if the position still has an open seat.

**What does "removed" mean?**
The organization ended the participation with a reason. Unlike withdrawal, removal does not free the seat.

**Why was my contribution rejected?**
Open the Submit Contribution page and look under the rejected contribution; the reason written by the organization appears there. Edit the submission and send it again.

**When does a submission become approved?**
When the organization verifies the contribution.

**Can a verified submission be rejected later?**
No. A verification is terminal.
