# Multiple Volunteers per Opportunity

## Rule
One opportunity can accommodate several volunteers, not only one.

## What This Means
- An organization can ask for more than one volunteer in the same opportunity.
- The organization can select several applicants.
- Each selected volunteer participates, submits their own contribution, and receives their own verification.

## Example
An organization publishes an opportunity for a cleanup campaign and needs 10 volunteers. It can select up to the number it needs from the applicants.

## Common Questions
**Can an opportunity accept many volunteers?**
Yes.

**Does each volunteer get their own Verified Experience?**
Each volunteer's contribution is reviewed and verified individually.

**Is there a maximum number of volunteers per opportunity?**
I do not have confirmed information about a maximum.
