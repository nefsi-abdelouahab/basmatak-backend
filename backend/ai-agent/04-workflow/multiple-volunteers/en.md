# Several Volunteers in One Opportunity

## The Rule

One opportunity can contain several positions, and each position can accept several volunteers. The required number of volunteers is set per position.

## What This Means

- The organization can ask for more than one volunteer in the same opportunity.
- Each position has its own required number and its own filled number.
- Each accepted volunteer has a separate participation, submits a separate contribution, and can receive a separate Verified Experience.
- A volunteer applies to a specific position, not to the opportunity as a whole.

## Example

An organization publishes a cleaning campaign with two positions: field volunteers and a documentation team. Each position can require several volunteers, and the organization accepts applicants for each position separately.

## Common Questions

**Can an opportunity accept several volunteers?**
Yes. Each position has its own required number of volunteers.

**Does each volunteer get a separate Verified Experience?**
Yes. Each volunteer's contribution is reviewed and verified separately.

**Is there a maximum number of volunteers in an opportunity?**
The limit is set by the required number in each position. I do not have confirmed information about a platform-wide maximum number of positions.

**What happens when a position is full?**
The position stops accepting new applications while it has no open seat.
