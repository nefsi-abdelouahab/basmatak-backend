# Applications Page

## What It Is
The page where a volunteer follows the applications they sent to opportunities and the state of each one.

## Who Uses It
Volunteers, after signing in.

## What It Is For
- Seeing which opportunities you applied to.
- Following the result of each application.

## Important
An application is a request. It does not make you a participant. The organization reviews applications and selects volunteers.

## Note
The exact status names are not confirmed in this knowledge base. Do not state specific statuses.

## Common Questions
**Where can I follow my applications?**
On the Applications page.

**What do the statuses mean?**
I do not have confirmed information about the exact status names. Check the Applications page.

**I applied but nothing happened. What now?**
The organization reviews applications and decides. You can follow the application on the Applications page.
