# أنواع الإشعارات (Notifications) ومستلموها

## داخل المنصة فقط

الإشعارات داخل المنصة. وتظهر في مركز الإشعارات (Notification Center) الذي يُفتح من رمز الجرس. ولا ترسل المنصة إشعارات نشاط عامة عبر البريد الإلكتروني. ويُستخدم البريد الإلكتروني فقط لتوثيق الحساب وإعادة تعيين كلمة المرور.

## عناوين مقروءة

يعرض كل إشعار عنواناً قصيراً مقروءاً، مثل "Application accepted" بالإنجليزية أو "تم قبول الطلب" بالعربية. ويتبع العنوان لغة الواجهة.

## الأنواع

| الإشعار | المستلم | التفضيل |
|---|---|---|
| تم استلام طلب جديد | المنظمة (Organization) التي تملك الفرصة (Opportunity) | applicationUpdates |
| تم قبول الطلب | المتطوع (Volunteer) المتقدم | applicationUpdates |
| تم رفض الطلب | المتطوع المتقدم | applicationUpdates |
| تم سحب الطلب | المتطوع المتقدم | applicationUpdates |
| تم سحب المشاركة | المنظمة التي تملك الفرصة | applicationUpdates |
| تمت إزالة المشاركة | المتطوع المشارك | applicationUpdates |
| تم إلغاء الفرصة | كل مشارك مقبول أو نشط | applicationUpdates |
| بدأت الفرصة | كل مشارك مقبول أو نشط | applicationUpdates |
| تم استلام مساهمة جديدة | المنظمة التي تملك الفرصة | verification |
| تم التحقق من المساهمة | المتطوع الذي أرسل المساهمة (Submission) | verification |
| تم رفض المساهمة | المتطوع الذي أرسل المساهمة | verification |
| تم تحديث التحقق من المنظمة | حساب المنظمة | verification |
| تم قفل النشر | المنظمة الناشرة | system |

## التفضيلات

التفضيلات الستة هي applicationUpdates وreviews وverification وsystem وdigest وrecordIssued. وكلها مفعّلة افتراضياً. وتتحكم applicationUpdates وverification وsystem فقط في أنواع الإشعارات الحالية. أما الثلاثة الأخرى فمفاتيح محفوظة لا تتحكم في أي حدث حالي.

## إدارة الإشعارات

يمكن للمستخدم تعليم إشعار واحد كمقروء أو تعليم الكل كمقروء. ويعرض مركز الإشعارات عدد غير المقروء ويسرد الإشعارات الأحدث أولاً.

## الأسئلة الشائعة

**هل سأتلقى إشعاراً عند قبول طلبي (Application)؟**
نعم. يُنشأ إشعار داخل المنصة للمتطوع.

**هل ستتلقى المنظمة إشعاراً عند إرسال مساهمتي؟**
نعم. يُنشأ إشعار داخل المنصة للمنظمة.

**هل ستتلقى المنظمة إشعاراً إذا سحبت مشاركتي؟**
نعم. عندما يسحب مشارك مشاركته، تتلقى المنظمة التي تملك الفرصة إشعاراً داخل المنصة.

**هل تُرسل الإشعارات عبر البريد الإلكتروني؟**
لا. يُستخدم البريد الإلكتروني فقط لتوثيق الحساب وإعادة تعيين كلمة المرور.

**هل يمكنني إيقاف نوع من الإشعارات؟**
نعم. يمكن إيقاف كل تفضيل، فتُكتم أنواع الإشعارات التي تعتمد عليه.

**هل تؤثر التفضيلات الستة كلها في الإشعارات؟**
لا. تتحكم applicationUpdates وverification وsystem فقط في أنواع الإشعارات الحالية.

**هل يمكنني تعليم كل الإشعارات كمقروءة؟**
نعم.
