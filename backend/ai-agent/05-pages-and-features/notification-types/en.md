# Notification Types and Recipients

## In-App Only

Notifications are in-app. They appear in the notification center reached from the bell. The platform does not send general activity notifications by email. Email is used only for account verification and password reset.

## Readable Titles

Each notification shows a short readable title, such as "Application accepted" in English or "تم قبول الطلب" in Arabic. The title follows the interface language.

## Types

| Notification | Recipient | Preference |
|---|---|---|
| New application received | The organization that owns the opportunity | applicationUpdates |
| Application accepted | The applying volunteer | applicationUpdates |
| Application rejected | The applying volunteer | applicationUpdates |
| Application withdrawn | The applying volunteer | applicationUpdates |
| Participation withdrawn | The organization that owns the opportunity | applicationUpdates |
| Participation removed | The participant volunteer | applicationUpdates |
| Opportunity cancelled | Each accepted or active participant | applicationUpdates |
| Opportunity started | Each accepted or active participant | applicationUpdates |
| New submission received | The organization that owns the opportunity | verification |
| Submission verified | The submitting volunteer | verification |
| Submission rejected | The submitting volunteer | verification |
| Organization verification updated | The organization account | verification |
| Publishing locked | The publishing organization | system |

## Preferences

The six preferences are applicationUpdates, reviews, verification, system, digest, and recordIssued. All are on by default. Only applicationUpdates, verification, and system gate current notification types. The other three are saved toggles that do not gate any current event.

## Managing Notifications

A user can mark one notification as read or mark all as read. The notification center shows the unread count and lists notifications newest first.

## Common Questions

**Will I be notified when my application is accepted?**
Yes. An in-app notification is created for the volunteer.

**Will the organization be notified when I submit a contribution?**
Yes. An in-app notification is created for the organization.

**Will the organization be notified if I withdraw my participation?**
Yes. When a participant withdraws, the organization that owns the opportunity receives an in-app notification.

**Are notifications sent by email?**
No. Email is used only for account verification and password reset.

**Can I turn off a type of notification?**
Yes. Each preference can be turned off, and the notification types that depend on it are suppressed.

**Do all six preferences affect notifications?**
No. Only applicationUpdates, verification, and system gate current notification types.

**Can I mark all notifications as read?**
Yes.
