# لا نظام مراسلة

## القرار

نظام المراسلة ليس جزءاً من الإصدار الأول للمنصة.

## ماذا يعني ذلك

- لا توجد دردشة مدمجة أو مراسلة مباشرة بين المستخدمين.
- يسير سير العمل في المنصة عبر طلبات التقديم (Application)، والاختيار، وتنفيذ المهام، والمساهمات (Contribution)، والتوثيق (Verification)، وليس عبر محادثات خاصة.

## التواصل مع منظمة

يعرض الملف العام للمنظمة (Organization) بريدها الإلكتروني للجميع؛ أما هاتفها فيظهر للمستخدمين المسجّلين الدخول فقط. ولا تستطيع بصمة عرض بريد المنظمة أو هاتفها، لذا افتح الملف العام للمنظمة لرؤية بيانات التواصل المتاحة لك. كما تتضمن صفحة إرسال المساهمة (Submit Contribution) رابط "مراسلة المنظمة عبر البريد الإلكتروني". ولا تعرض المنصة البريد الإلكتروني أو الهاتف الخاص بالمتطوع للمنظمات.

## بصمة ليست نظام مراسلة

تجيب بصمة عن الأسئلة المتعلقة بالمنصة. وهي ليست وسيلة لإرسال رسائل إلى مستخدمين آخرين.

## الأسئلة الشائعة

**هل يمكنني إرسال رسالة إلى منظمة أو إلى متطوع؟**
ليس عبر المنصة. فنظام المراسلة ليس جزءاً من الإصدار الأول.

**هل توجد دردشة بين المتطوعين والمنظمات؟**
لا. يتم التنسيق عبر سير عمل الفرصة (Opportunity) وبيانات التواصل العامة للمنظمة.

**هل ترى المنظمة بريدي الإلكتروني أو هاتفي؟**
لا. لا ترى المنظمات البريد الإلكتروني أو الهاتف الخاص بالمتطوع.

**كيف أتواصل مع منظمة؟**
افتح ملفها العام: البريد الإلكتروني عام، ويظهر الهاتف عندما تكون مسجّلاً الدخول. ولا تستطيع بصمة عرض أيهما. ويمكنك أيضاً استخدام رابط "مراسلة المنظمة عبر البريد الإلكتروني" في صفحة إرسال المساهمة.

**هل بصمة دردشة مع المنظمة؟**
لا. فهي تجيب فقط عن الأسئلة المتعلقة بالمنصة.
