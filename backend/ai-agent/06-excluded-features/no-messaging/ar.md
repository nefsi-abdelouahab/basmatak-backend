# لا نظام مراسلة

## القرار

نظام المراسلة ليس جزءاً من الإصدار الأول للمنصة.

## ماذا يعني ذلك

- لا توجد دردشة مدمجة أو مراسلة مباشرة بين المستخدمين.
- يسير سير العمل في المنصة عبر طلبات التقديم (Application)، والاختيار، وتنفيذ المهام، والمساهمات (Contribution)، والتوثيق (Verification)، وليس عبر محادثات خاصة.

## التواصل مع منظمة

يمكن للمتطوع (Volunteer) استخدام بيانات التواصل العامة للمنظمة (Organization) على ملفها العام. كما تتضمن صفحة إرسال المساهمة (Submit Contribution) رابط "مراسلة المنظمة عبر البريد الإلكتروني". ولا تعرض المنصة البريد الإلكتروني أو الهاتف الخاص بالمتطوع للمنظمات.

## المساعد الذكي ليس نظام مراسلة

يجيب المساعد الذكي عن الأسئلة المتعلقة بالمنصة. وهو ليس وسيلة لإرسال رسائل إلى مستخدمين آخرين.

## الأسئلة الشائعة

**هل يمكنني إرسال رسالة إلى منظمة أو إلى متطوع؟**
ليس عبر المنصة. فنظام المراسلة ليس جزءاً من الإصدار الأول.

**هل توجد دردشة بين المتطوعين والمنظمات؟**
لا. يتم التنسيق عبر سير عمل الفرصة (Opportunity) وبيانات التواصل العامة للمنظمة.

**هل ترى المنظمة بريدي الإلكتروني أو هاتفي؟**
لا. لا ترى المنظمات البريد الإلكتروني أو الهاتف الخاص بالمتطوع.

**كيف أتواصل مع منظمة؟**
استخدم بيانات التواصل العامة على ملفها العام، أو رابط "مراسلة المنظمة عبر البريد الإلكتروني" في صفحة إرسال المساهمة.

**هل المساعد الذكي دردشة مع المنظمة؟**
لا. فهو يجيب فقط عن الأسئلة المتعلقة بالمنصة.
