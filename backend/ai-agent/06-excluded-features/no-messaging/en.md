# No Messaging System

## The Decision
A messaging system was not included in the first version of the platform.

## What This Means
- There is no built-in chat or direct messaging between users in the current design.
- The platform's workflow runs through applications, selection, task execution, contributions, and verification, not through private conversations.

## Contacting an Organization
For contact details, use the organization's contact information where available. The contact details of the Roeya Association, the organization behind the platform, are in the contact topic.

## The AI Assistant Is Not Messaging
The AI assistant answers questions about the platform. It is not a way to send messages to other users.

## Common Questions
**Can I send a message to an organization or a volunteer?**
Not through the platform. A messaging system is not part of the first version.

**Is there a chat between volunteers and organizations?**
No. Coordination happens through the opportunity workflow.

**Is the AI assistant a chat with the organization?**
No. It only answers questions about the platform.
