# Why These Product Decisions

## Excluded from the First Version

| Feature | Decision |
|---|---|
| Followers | Not included |
| Likes | Not included |
| Popularity ranking | Not included |
| Messaging | Not included in the first version |
| Skill badges | Not included |
| Organization members model | Not included |
| Social popularity system | Rejected |

## The Reasoning

These decisions define the identity of the product and keep it from turning into a traditional social network.

1. Real contribution matters more than attention. Followers and likes do not prove that someone did volunteering work.
2. Verified experience is more valuable than popularity.
3. Skills should be proven through contributions, not shown as decorative symbols.
4. The first version stays simple and focused on the core function: managing the full volunteering cycle.

## The Core Function the First Version Proves

1. Publish an opportunity.
2. Receive applications.
3. Select volunteers.
4. Follow participation.
5. Receive contributions.
6. Verify contributions.
7. Show Verified Experiences.

## Communication Without Messaging

The platform still supports the communication the workflow needs: cover messages with applications, rejection and removal reasons, verification notes, review comments, and in-app status notifications. Organizations can publish their public contact details, and volunteers can use the "Email the organization" link on the Submit Contribution page.

## Common Questions

**Why no messaging?**
The first version focuses on the volunteering cycle and its verification. Messaging is not part of that scope.

**How do volunteers and organizations communicate?**
Through the workflow: cover messages, reasons, notes, review comments, notifications, and the organization's public contact details.

**Will these features be added later?**
I do not have confirmed information about future plans for them.

**Does excluding these features make the platform less useful?**
The platform focuses on documenting real contributions and verifying them, which is its main value.
