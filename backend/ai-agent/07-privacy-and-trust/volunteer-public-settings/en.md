# Volunteer Public Profile Settings

## Public Profile On by Default

A volunteer's public profile is enabled by default. It can be turned off from the settings.

## What Is Shown by Default

| Element | Default |
|---|---|
| Biography | Shown |
| Skills | Shown |
| Experiences | Shown |
| Portfolio | Shown |
| Statistics | Shown |
| Avatar | Hidden |
| Location | Hidden |
| Availability | Hidden |

The full name is always shown on the public profile. Email and phone are never shown.

## What a Volunteer Can Change

A volunteer can turn each of these blocks on or off from the public profile settings. When a block is off, it is not shown publicly.

## Public Profile and Discover Talents

A profile that is not public does not appear in Discover Talents. Only public data is used on public pages.

## Common Questions

**Is my public profile on by default?**
Yes.

**What is shown by default?**
Biography, skills, experiences, portfolio, and statistics.

**Is my location public by default?**
No. Location is hidden by default.

**Can I hide my skills?**
Yes, from the public profile settings.

**Is my full name always public?**
Yes. The full name is always shown on the public profile.

**Can people see my email or phone?**
No. Email and phone are never shown on the public profile.

**Does turning off my public profile remove me from Discover Talents?**
Yes. A profile that is not public does not appear there.
