# Who Can Do What

This table summarizes the verified permissions. The platform enforces them.

| Action | Visitor (not signed in) | Volunteer | Organization |
|---|---|---|---|
| Explore public opportunities | Yes | Yes | Yes |
| View public profiles and talents | Yes | Yes | Yes |
| View public organization profiles | Yes | Yes | Yes |
| View public verified experiences | Yes | Yes | Yes |
| Manage own profile | No | Yes | Yes (organization profile) |
| Apply to a position | No | Yes | No |
| Withdraw own application | No | Yes | No |
| Submit a contribution | No | Yes | No |
| Manage own portfolio | No | Yes | No |
| Publish, edit, close, or cancel an opportunity | No | No | Yes |
| Review applications and accept or reject them | No | No | Yes |
| Remove a participant | No | No | Yes |
| Review and verify or reject a contribution | No | No | Yes |
| Write a review of a contribution | No | No | Yes |
| Receive Verified Experiences | No | Yes | No |
| Delete own account | No | Yes | Yes |

## Security Rules

- Actions that change data are validated by the platform.
- The platform never trusts a user's claim about their role, and never trusts role information produced by an AI model.
- Only the organization side can verify contributions and write reviews.
- The assistant has no access to accounts and cannot perform any of these actions.

## Common Questions

**Who can verify a contribution?**
Only the organization responsible for the activity.

**Can an organization apply to an opportunity as a volunteer?**
No. Applying is a volunteer action. An organization account is for publishing and managing opportunities.

**Can a volunteer review an organization?**
No. Reviews are organization-to-volunteer only.

**Can a visitor do anything that changes data?**
No. Visitors browse public pages only.

**Why can't I do something I expected to do?**
Actions depend on your account type. If you are not signed in, you have visitor access only.
